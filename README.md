# Цитадель Физио — многостраничный сайт физиотерапевтического центра

Корпоративный сайт / медицинский лендинг для сети физиотерапевтических клиник «Цитадель Физио».

## Структура

```
citadel_phisio/
├── assets/
│   ├── fonts/
│   ├── icons/
│   └── images/
├── css/
│   ├── style.css          # глобальные стили, токены, компоненты
│   ├── components.css     # (заготовка) повторяемые блоки
│   └── pages.css          # (заготовка) стили страниц
├── js/
│   ├── main.js            # меню-бургер
│   └── accessibility.js   # панель доступности + localStorage
├── index.html
├── specialists.html
├── technologies.html
├── documents.html
├── landing-pain.html
├── landing-spine.html
├── landing-joints.html
├── landing-health.html
└── landing-nerves.html
```

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
npx serve .
# или
python -m http.server 8080
```

## Особенности

- Светлая песочно-молочная палитра с золотыми акцентами
- Шрифты: Cormorant Garamond + Inter
- Полная адаптивность (320px → 4K)
- Панель доступности с сохранением настроек в `localStorage`
- Hover-эффекты и визуальная кликабельность карточек

## Доступность

Кнопка «глаз» в левом нижнем углу открывает панель настроек:
- размер шрифта
- читаемый шрифт
- высота строки, межбуквенный интервал
- темы (светлая / высокий контраст / монохром)
- скрытие изображений, подсветка ссылок и др.

Настройки сохраняются между сессиями.
